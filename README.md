# Games

סימולציה עסקית כקובץ HTML סטטי אחד — ללא שלב בנייה, ללא
`node_modules` וללא CDN חיצוני. אפשר לפתוח אותו ישירות בדפדפן, להעלות את
התיקייה כמו שהיא ל-Cloudflare Pages, ולהתקין אותו על הטלפון כאפליקציה.

| משחק | תיאור | תיקייה |
|---|---|---|
| **מסלול הברזל** | סימולציית קריירה בתעשיית הטכנולוגיה. בוחרים חברה לנהל מ-2025, ומעבר טכנולוגי קורה רק אם מישהו מימן אותו במו״פ — אין תאריכים קשיחים. עשר חברות לבחירה, מגדיר מכשיר מודולרי, כנסי חשיפה וביקורות, אקוסיסטם והכנסות חוזרות, שוק טאלנטים עם משא ומתן, מיזוגים ורכישות, שרשרת אספקה ותקציב שחור. | [`tech-tycoon/`](tech-tycoon/) |
| **מעגל הצבעים** | פאזל צבעים בהשראת Zuma/Loop Master. שרשרת כדורים זזה סביב לולאה אל עבר בור; יורים כדורים מהמרכז ליצירת שלשות תואמות שנפלטות, עם שרשראות תגובה ומכפילי שילוב. 24 שלבים בעקומת קושי עולה, מפת שלבים עם דירוג כוכבים, ומנוע נבדק ב-Node לאיזון. | [`color-loop/`](color-loop/) |

## פריסה ל-Cloudflare Pages

```bash
npx wrangler pages deploy .
```

או דרך הממשק: Workers & Pages → Create → Pages → Connect to Git → בחירת
המאגר. **Build command** נשאר ריק, **Build output directory** הוא `/`.

המשחק יהיה זמין בנתיב `example.pages.dev/tech-tycoon/`.

## הערות טכניות

* המשחק ב-RTL מלא ובעברית, ומותאם למסכי מגע.
* שמירה אוטומטית ב-`localStorage` של הדפדפן.
* הגרפים נכתבו ידנית ב-SVG במקום ספריית תרשימים, כדי שהמשחק ירוץ גם
  בסביבות שחוסמות סקריפטים חיצוניים וגם בלי חיבור לרשת.
* הגופנים נטענים מ-Google Fonts עם fallback מלא — בלי רשת המשחק עדיין תקין.
* service worker שומר את המשחק במטמון, כך שאחרי ביקור אחד הוא רץ גם במצב טיסה.
* מנוע הסימולציה מופרד מה-DOM וניתן להרצה ב-Node לצורך בדיקות איזון
  (ראו `tech-tycoon/README.md`).
