# Games

משחקי סימולציה עסקית. כל משחק הוא קובץ HTML סטטי אחד — ללא שלב בנייה, ללא
`node_modules` וללא CDN חיצוני. אפשר לפתוח כל אחד מהם ישירות בדפדפן, או
להעלות את התיקייה כמו שהיא ל-Cloudflare Pages.

| משחק | תיאור | תיקייה |

| **מסלול הברזל** | סימולציית קריירה בתעשיית הטכנולוגיה. בוחרים חברה לנהל מ-2025, ומעבר טכנולוגי קורה רק אם מישהו מימן אותו במו״פ — אין תאריכים קשיחים. עשר חברות לבחירה, מגדיר מכשיר מודולרי, כנסי חשיפה וביקורות, אקוסיסטם והכנסות חוזרות, שוק טאלנטים עם משא ומתן, מיזוגים ורכישות, שרשרת אספקה ותקציב שחור. | [`tech-tycoon/`](tech-tycoon/) |
| **כס המנכ״ל** | 96 חודשים כמנכ״ל סמסונג אלקטרוניקס, 2025–2032. הקצאת מו״פ, בניית פאבים, תזמון השקות ומחזור מחירי הזיכרון. מכויל לדוחות 2024–2025 האמיתיים. | [`samsung-ceo/`](samsung-ceo/) |

## פריסה ל-Cloudflare Pages

```bash
npx wrangler pages deploy .
```

או דרך הממשק: Workers & Pages → Create → Pages → Connect to Git → בחירת
המאגר. **Build command** נשאר ריק, **Build output directory** הוא `/`.

כל משחק יהיה זמין בנתיב שלו, למשל `example.pages.dev/tech-tycoon/`.

## הערות טכניות

* כל המשחקים ב-RTL מלא ובעברית.
* שמירה אוטומטית ב-`localStorage` של הדפדפן.
* הגרפים נכתבו ידנית ב-SVG במקום ספריית תרשימים, כדי שהמשחקים ירוצו גם
  בסביבות שחוסמות סקריפטים חיצוניים וגם בלי חיבור לרשת.
* הגופנים נטענים מ-Google Fonts עם fallback מלא — בלי רשת המשחק עדיין תקין.
* מנוע הסימולציה בכל משחק מופרד מה-DOM וניתן להרצה ב-Node לצורך בדיקות
  איזון (ראו `tech-tycoon/README.md`).
