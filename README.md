# Games

סימולציות עסקיות כאתרים סטטיים — ללא שלב בנייה, ללא `node_modules` וללא CDN
חיצוני. אפשר לפתוח כל אחת ישירות בדפדפן, להעלות את התיקייה כמו שהיא
ל-Cloudflare Pages, ולהתקין אותה על הטלפון כאפליקציה.

| משחק | תיאור | תיקייה |
|---|---|---|

| **אימפריית טק** | סימולציית תעשיית הטכנולוגיה עם חברות אמיתיות — Apple, Samsung, Google, Xiaomi, Sony, Meta, Microsoft, Nothing — או סטארטאפ שאתם מקימים מאפס. שוק בגודל אמיתי עם מחזור החלפה, קווי ייצור ומלאי מת, אקוסיסטם שנועל לקוחות, חטיפת כישרונות מיריבות, שרשרת אספקה (TSMC, Foxconn, Samsung Display), דירקטוריון שמתחלף כשהחברה גדלה, ומצב יוצר תוכן עם שחיקה ואלגוריתם — שאפשר להמיר לכיסא מנכ״ל. עיצוב זכוכית כהה בסגנון iOS. | [`tech-empire/`](tech-empire/) |

## פריסה ל-Cloudflare Pages

```bash
npx wrangler pages deploy .
```

או דרך הממשק: Workers & Pages → Create → Pages → Connect to Git → בחירת
המאגר. **Build command** נשאר ריק, **Build output directory** הוא `/`.

כל משחק זמין בנתיב שלו, למשל `example.pages.dev/tech-empire/`.

## הערות טכניות

* המשחק ב-RTL מלא ובעברית, ומותאם למסכי מגע.
* שמירה אוטומטית ב-`localStorage` של הדפדפן.
* הגרפים נכתבו ידנית ב-SVG במקום ספריית תרשימים, כדי שהמשחק ירוץ גם
  בסביבות שחוסמות סקריפטים חיצוניים וגם בלי חיבור לרשת.
* הגופנים נטענים מ-Google Fonts עם fallback מלא — בלי רשת המשחק עדיין תקין.
* service worker שומר את המשחק במטמון, כך שאחרי ביקור אחד הוא רץ גם במצב טיסה.
* מנוע הסימולציה מופרד מה-DOM וניתן להרצה ב-Node לצורך בדיקות איזון:
  `node tech-empire/test/balance.js`.
